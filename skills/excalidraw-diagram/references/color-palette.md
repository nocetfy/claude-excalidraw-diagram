# 配色（唯一来源）

什么时候上色，见 SKILL.md 的"用色：少即是多"。这里只管用哪个值。

## 中性色（默认，绝大多数元素都用它）

| 用在哪里 | 值 |
|---|---|
| 节点、格子 | `backgroundColor: "#ffffff"`，`strokeColor: "#868e96"`，`strokeWidth: 1` |
| 文字 | `#1e1e1e` |
| 连线、箭头 | `#495057`，`strokeWidth: 1.5` |
| 淡化：外部系统、已删除或空着的位置、和结论无关但必须画出来的部分 | `backgroundColor: "#f1f3f5"`，框同上。还要更弱时用虚线框，文字用 `#868e96` |
| 背景 | `#ffffff` |

## 彩色

每个色系两个值。**底色**铺在形状里；**字线色**用于彩色的文字、连线和箭头。

上了底色的形状，框仍然用中性的细灰线，里面的文字仍然用 `#1e1e1e`。颜色出现在底色这一处就够了，框和字再跟着变色只会更吵。

| 色系 | 底色 | 字线色 |
|---|---|---|
| 蓝 | `#d0ebff` | `#2a5fb7` |
| 黄 | `#fff3bf` | `#ab6100` |
| 绿 | `#d3f9d8` | `#277539` |
| 红 | `#ffe3e3` | `#a72721` |
| 紫 | `#e5dbff` | `#824fbf` |
| 青 | `#c5f6fa` | `#357f95` |
| 葡萄 | `#f3d9fa` | `#b2468a` |

字线色对白底的对比度都不低于 4.5:1，可以直接当文字色。

## 取哪个色

| 用途 | 取色 |
|---|---|
| 焦点，只有一种 | 蓝 |
| 焦点是两方的关系：读和写、来源和去向、改动前后 | 蓝、黄 |
| 焦点有好坏之分：成功和失败、正确和错误 | 绿、红。通常只有一边需要强调，就只上那一边；最常见的是只给失败分支上红色 |
| 本次改动：技术方案里新增或修改的部分 | 紫 |
| 对应：同一个量、同一个参与方 | 依次取蓝、黄、紫、青、葡萄。红和绿带有好坏的含义，留给上一行 |

同一张图里，一种颜色只表示一个意思。

## 连线

| 用途 | strokeColor | 线型 |
|---|---|---|
| 默认 | `#495057` | 实线 |
| 失败或异常分支 | `#a72721` | 实线 |
| 回环、重试 | `#a72721` | `strokeStyle: "dashed"` |
| 异步调用、返回消息 | 沿用它本来的颜色 | `strokeStyle: "dashed"` |
| 时序图的消息 | 发起方的字线色 | 调用用实线，返回用虚线 |
| 时序图生命线（`line`） | `#adb5bd` | `strokeStyle: "dashed"`，`strokeWidth: 1` |

连线标签的文字：`#495057`，`fontSize: 16`。时序图的消息标签是图里的主要内容，用深一档的 `#343a40`。

## 分组框（系统、服务、分层边界）

- 框：`backgroundColor: "transparent"`、`strokeColor: "#868e96"`、`strokeStyle: "dashed"`、`strokeWidth: 1`
- 标题：在框内左上角放一个自由文字（x+16、y+12），`fontSize: 20`、`strokeColor: "#495057"`
- 需要突出某一方时，把那一方的框和标题改成对应色系的字线色。框仍然是透明虚线，不要整框铺色。

## 文字

| 层级 | strokeColor | fontSize |
|---|---|---|
| 图标题（可选） | `#1e1e1e` | 28 |
| 分组标题 | `#495057` | 20 |
| 节点文字 | `#1e1e1e` | 18 |
| 连线标签 | `#495057`（时序图的消息标签 `#343a40`） | 16 |
| 注释、备注 | `#868e96` | 14 到 16 |
| 彩色文字：和某个上了色的形状是同一个量时才用 | 该色系的字线色 | 按所在层级 |

## 代码和数据片段（可选，少用）

浅色框：`backgroundColor: "#f8f9fa"`、`strokeColor: "#dee2e6"`。文字用 `fontFamily: 3`（等宽）、`fontSize: 14`、`#1e1e1e`、左对齐。不要用深色代码块。
